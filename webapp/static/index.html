영수증 정리

영수증 사진을 올리면 반듯하게 펴서, 내용을 읽고, 식자재 지출현황 엑셀로 만들어 드립니다

파일 이름은 자동으로 단순하게 정리됩니다. 예: KakaoTalk_20260813_142355123.jpg → 26.08.13 (같은 날 사진이 여러 장이면 26.08.13_2, 26.08.13_3 ...), 8.21 충북농산 → 26.08.21 충북농산. 날짜로 읽히지 않는 이름은 그대로 둡니다.

시험 서버는 재시작·재배포 시 작업 파일이 지워질 수 있으므로 결과는 바로 다운로드해 주세요. 남아 있는 영수증은 정리가 끝난 뒤 7일이 지나면 자동으로 지워지고, 결과 화면의 '지금 삭제' 버튼으로 바로 지울 수도 있습니다. 읽은 금액은 AI가 판독한 값이므로 엑셀로 쓰기 전에 '확인 필요'로 표시된 영수증을 꼭 한 번 확인해 주세요.
